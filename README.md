# Club Gimnasia Sagunto

Plataforma web para la gestión del club de gimnasia y la comunicación con las familias.

## Descripción del proyecto

Este proyecto consiste en desarrollar una plataforma web para centralizar la información deportiva y organizativa del Club Gimnasia Sagunto. El objetivo es facilitar la comunicación entre la junta directiva, los entrenadores, los deportistas y sus familias, evitando que los horarios, avisos y convocatorias estén repartidos por diferentes canales.

## Contexto académico

Proyecto desarrollado en el módulo de **Proyecto Intermodular de 2.º del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW)**.

## Funcionalidades previstas

La primera versión de la aplicación incluirá:

- Gestión de grupos, categorías, deportistas y responsables.
- Calendario de entrenamientos, competiciones, exhibiciones y otros eventos.
- Publicación de avisos y comunicaciones por grupo.
- Confirmación de asistencia a eventos y convocatorias.
- Panel de administración y área privada para familias o deportistas.

En función de las necesidades del club y del tiempo restante, se podrán incorporar otras funcionalidades, como la gestión documental, el registro de asistencia, las noticias o las notificaciones automáticas.
