# Club Gimnasia Sagunto

Plataforma web para la gestión del club de gimnasia y la comunicación con las familias.

## Descripción del proyecto

Este proyecto consiste en diseñar y desarrollar una plataforma web para centralizar la información deportiva y organizativa del Club Gimnasia Sagunto.

El objetivo es facilitar la comunicación y la coordinación entre la junta directiva, los entrenadores, los deportistas y sus familias, evitando que los horarios, avisos, convocatorias y eventos estén repartidos por diferentes canales.

La plataforma pretende ofrecer un entorno sencillo, accesible y organizado, adaptado a las necesidades del club.

## Contexto académico

Proyecto desarrollado en el módulo de **Proyecto Intermodular de 2.º del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW)**.


## Funcionalidades previstas

La primera versión de la aplicación incluirá las siguientes funcionalidades:

- Gestión de grupos y categorías.
- Gestión de deportistas y sus responsables legales.
- Calendario de entrenamientos, competiciones, exhibiciones y otros eventos.
- Publicación de avisos y comunicaciones dirigidos a grupos específicos.
- Confirmación de asistencia a eventos y convocatorias.
- Panel de administración para la gestión del club.
- Área privada para familias y deportistas.


## Estado del proyecto

Actualmente, el proyecto se encuentra en la fase inicial de planificación y preparación del entorno de desarrollo.

Se están definiendo las funcionalidades principales, las herramientas de trabajo colaborativo y las decisiones técnicas necesarias para comenzar la implementación.
